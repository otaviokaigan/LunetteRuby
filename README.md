# LunetteRuby

> **Status:** In development

This is my new project for practice networking ideas.

LunetteRuby is a scanner that checks for open ports on 254 IP addresses and displays the results on a dashboard developed with Sinatra. This project is still in its early stages.

## Installation & Quick Start

To get the LunetteRuby working, you just need to install the dependent gems:

1. **Ruby**: Ensure you have Ruby installed on your system (Ruby 3.0 or later is recommended).
2. **Bundler**: Make sure you have the Bundler gem installed to manage dependencies:
    ```bash
    gem install bundler
    ```
3. Clone the repository
    ```bash
    git clone https://github.com/otaviokaigan/LunetteRuby.git
    cd LunetteRuby
    ```
4. Install the required dependencies:
    ```bash
    bundle install
    ```
5. Start the application server:
    ```bash
    bundle exec rackup
    ```
6. Open your browser and access:
    ```bash
    http://localhost:9292
    ```
